### Added
- T16a (E2a): модуль решений `decision/` и стратегии-плагины `strategies/`. Chief Trader запускает стратегии задачи (`strategies:` в `config/schedule.yaml`: T−7 — режим A, T−3 — ворота B, T−1 — B, стрэддл, iron condor), проверяет ворота (edge > издержки + 0,03, уверенность ≥ θ, карантин — только режим C, дата подтверждена), Capital Manager считает риск по Келли (⅛ в сезоны 1–2, b по истории конструкции) с поправками Black Swan и ручным красным уровнем (`risk_limits.black_swan.manual_red`). Шаги каждой стратегии — в `decision_step` (миграция 0014); `Decision` у события один: ENTERED при первом прошедшем предложении, иначе после T0 — SKIPPED с кодами всех отказов. Стадии: режимы A и B — shadow, стрэддл и кондор — paper (SPEC §17). Издержки — доля от максимального убытка конструкции по `CostModel`; эталон `move_ratio` — частота из архива (решения заказчика 15.10.2026); спред акции без котировок — допущение 0,05%.

Шапка «СБОЙ» — только по нерешённым ошибкам. `make rerun-job ARGS="NFLX T-7 options"` — повторить упавшую задачу с тем же моментом оценки. Миграция 0012: `error_log.resolved_at`.

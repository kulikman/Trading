### Added
- E10-2a: Real-карточки (`execution/real.py`, миграция 0022 `trade_card.risk_usd`) — стратегия в стадии live_small / live при прошедшем решении получает, кроме paper-карточки, Real-карточку: риск = капитал Real (`make cash`) × размер по SPEC (`decision.capital.size_real`: Келли или фиксированный риск без модели, вето и множители Black Swan по уровню дня, вес стадии, × 0,5 первые 30 дней с первого пополнения — `sizing.real_first_days`), единиц = риск / риск единицы плана стратегии. Ордера плана ставятся ручным брокером (`broker_order`), карточка PLANNED → ARMED; «ДЕЙСТВИЕ» показывает строки ордеров и риск в $; «Исполнено» подтверждает только вход — стоп-ордер остаётся. Не открылась (нет пополнений, меньше одной единицы, вето) — сообщение «СИСТЕМА» с причиной. План ордеров пока есть у режима C (акция: лимит VWAP ± 0,3%, стоп 2 × ATR); у опционных конструкций — следующий шаг.
- E10-1: метрики для `promote` (`learning/evidence.py`) — стратегия: Sharpe доходности на риск закрытых paper-сделок (в shadow — теневых сделок), базовый уровень 0, наблюдения — число сделок (правило 30); агент: Brier p_up с его признаками и без них из последнего обучения сезона. `make promote ARGS="mode_c"` больше не отказывает всегда «мало наблюдений»; на сервере — `make server-promote ARGS="mode_c"`.
- E2d-2: отбор недели (`decision/week.py`, SPEC §17 п.2) — одна функция для экрана «Неделя» и понедельничного дайджеста: события ближайших 5 торговых дней, ожидаемая прибыль = риск $ × (p·b − (1−p)) по последнему прошедшему шагу каждой стратегии (лучшая стратегия события), b — по закрытым сделкам конструкции (правило 30); топ-5 — по ожидаемой прибыли с режимом, конструкцией и уверенностью, остальные — по дате со статусом и кодами. Режим C без модели и события без решения в топ не входят. Дайджест понедельника — тот же список.
- E2d-1: уровень Black Swan по дням — ежедневная задача `market-daily` (06:05 ET, `agents/macro/daily.py`, миграция 0021 `market_level`): уровень на закрытии каждого торгового дня окна `agents.macro.lookback_days` по тому же правилу, что у агента «Макро» (VIX FRED, SPY Massive).

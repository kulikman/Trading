# web — дашборд Earnings Engine (T19b)

Только чтение. Все числа, формулы и сортировки приходят готовыми из API (`api/`, T19a);
запросы к API — только с сервера, токен в браузер не попадает (`DASHBOARD.md` §7).

Запуск локально (решение заказчика 14.10.2026):

1. `make run-api` в корне репозитория (нужен `DASHBOARD_API_TOKEN` в `.env`);
2. `make run-web` — сайт на http://127.0.0.1:3000 (только этот компьютер, не локальная сеть).

Переменные окружения сайта: `DASHBOARD_API_TOKEN` (тот же, что у API) и `DASHBOARD_API_URL`
(по умолчанию `http://127.0.0.1:8000`).
